# Ballistix visual materials

Runtime materials are currently generated by PrototypeBootstrap so the prototype runs without imported binary assets.

Palette:
- ArenaFloor: graphite metal/stone
- Center: brushed metal plate
- Bottom: electric blue
- Right: amber
- Top: neon green
- Left: red
- Ball: polished steel

Next art pass will replace these runtime primitives with authored meshes/materials while keeping the gameplay colliders and slot system independent.
